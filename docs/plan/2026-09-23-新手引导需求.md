# 新手流程优化与使用说明计划

## Summary

修复“没有豆种档案也可以进入新建批次”的流程问题，并补充一套适合新用户的操作引导。

整体采用：

```text
首页步骤卡 + 关键页面前置拦截 + 全局帮助入口
```

不使用首次登录强制弹窗，不新增数据库表，不改变现有数据模型。

## Key Changes

### 1. 修复批次创建前置条件

豆种档案是库存批次的前置数据，入口和表单页都要进行保护。

- 当用户没有任何豆种档案时：
  - 库存页顶部“新增批次”改为“先添加豆种”。
  - 库存空状态按钮改为“先添加豆种”。
  - 点击后进入：
    ```text
    /beans/new?returnTo=/inventory/new
    ```
  - 不直接展示无法保存的批次表单。
- 用户创建豆种成功后：
  - 自动返回：
    ```text
    /inventory/new?bean=<新豆种ID>
    ```
  - 批次表单自动选中刚创建的豆种。
- 直接访问 `/inventory/new` 时，如果没有豆种：
  - 展示明确的空状态页面。
  - 说明“创建批次前需要先建立豆种档案”。
  - 提供“创建豆种”和“返回库存”按钮。
- `BatchForm` 仍保留提交时的 `bean_profile_id` 校验，防止异常状态绕过页面拦截。
- `returnTo` 只允许内部固定路径 `/inventory/new`，不接受任意外部跳转地址。

### 2. 同步修复冲煮记录流程

冲煮记录依赖可冲煮的库存批次，因此同步优化相似问题。

- 新建冲煮页面没有可用批次时，不展示空的表单。
- 展示说明：
  - 需要先创建库存批次。
  - 批次状态需要为“可开封”或“使用中”。
- 提供返回库存和创建批次入口。
- 冲煮列表页、首页“快速记录”按钮和日历“新增冲煮”入口都不能把用户带入无法完成的表单。
- `BrewForm` 保留最终提交校验，作为第二层保护。

### 3. 首页增加“开始使用”步骤卡

在 Dashboard 增加一个静态步骤卡，展示当前用户的使用进度：

```text
1. 创建豆种档案
2. 记录购买批次
3. 记录一次冲煮
4. 在日历中复盘和补充照片
```

行为规则：

- 没有完成的步骤显示主要操作按钮。
- 已完成步骤显示完成状态。
- 后续步骤在前置条件未完成时显示为锁定状态。
- 创建豆种后，第二步自动变为可操作。
- 创建可用批次后，第三步自动变为可操作。
- 有冲煮记录后，步骤卡转为简化状态，但仍可通过帮助入口查看完整说明。
- 不使用 `localStorage` 保存关闭状态，也不强制弹窗，避免用户误关后找不到说明。

Dashboard 需要额外读取当前用户的豆种档案数量，和已有的批次、冲煮记录一起计算步骤状态。

### 4. 增加全局使用说明入口

在 Layout 增加帮助按钮：

- 桌面端：放在侧边栏的语言切换附近。
- 移动端：放入移动端菜单，避免顶部按钮过多。
- 使用 `CircleHelp` 或同类 Lucide 图标。
- 点击打开帮助弹窗或侧边面板。
- 弹窗内容包括：
  - 产品解决什么问题。
  - 豆种档案和购买批次的区别。
  - 推荐使用顺序。
  - 什么时候记录冲煮。
  - 日历如何自动显示冲煮记录。
  - 如何补充当天照片和备注。
  - 库存状态和养豆倒计时的含义。
- 帮助内容为静态文案，不保存到数据库。
- 支持中文和英文、深色模式、手机视口。
- 支持关闭按钮、遮罩点击关闭和 `Escape` 关闭。

建议新增可复用的帮助组件，例如：

```text
src/components/UsageGuide.tsx
```

组件接收：

```ts
interface UsageGuideProps {
  open: boolean;
  onClose: () => void;
}
```

### 5. 增加完整双语文案

新增中文和英文翻译 key，覆盖：

- 先添加豆种。
- 创建批次前置说明。
- 没有可用批次。
- 豆种、批次、冲煮、日历的使用顺序。
- 步骤完成和锁定状态。
- 帮助入口、帮助标题、关闭按钮。
- 空状态、异常状态和返回操作。

所有新增用户可见文案都通过 `t()` 获取，不在组件中直接写死中英文。

## 主要文件和接口调整

- `InventoryList.tsx`
  - 读取豆种档案状态。
  - 根据是否存在豆种生成不同的新增入口。
- `BatchForm.tsx`
  - 增加无豆种档案的前置空状态。
  - 支持 `bean` 和受限的 `returnTo` 查询参数。
- `BeanForm.tsx`
  - 创建成功后，根据 `returnTo` 返回新建批次页面。
- `BrewForm.tsx`
  - 增加无可用批次的前置空状态。
- `BrewsList.tsx`、`Dashboard.tsx`、`Calendar.tsx`
  - 调整新增冲煮入口，避免把用户带入无法完成的流程。
- `Dashboard.tsx`
  - 增加步骤卡，并读取豆种档案完成状态。
- `Layout.tsx`
  - 增加帮助入口和帮助弹窗状态。
- `src/components/UsageGuide.tsx`
  - 新增可复用使用说明组件。
- `src/lib/i18n.ts`
  - 增加所有中英文文案。

不新增数据库表，不修改 Supabase schema，不修改现有业务查询和 RLS 逻辑。

## Test Plan

### 批次流程

- 无豆种时访问 `/inventory`：
  - 顶部按钮显示“先添加豆种”。
  - 空状态按钮显示“先添加豆种”。
- 无豆种时直接访问 `/inventory/new`：
  - 显示前置说明，不显示可提交的批次表单。
- 从库存页进入创建豆种：
  - 创建成功后自动跳转到 `/inventory/new?bean=<id>`。
  - 新批次表单自动选中该豆种。
- 有豆种时：
  - 原有批次创建流程正常。
  - 编辑批次流程不受影响。
- 手动清空或绕过豆种选择提交：
  - 仍然不能发起无效保存请求。

### 冲煮流程

- 没有批次时访问 `/brews/new`：
  - 显示需要先创建批次的说明。
- 只有 `pending` 或 `resting` 批次时：
  - 显示需要可用批次的说明。
- 存在 `ready` 或 `in_use` 批次时：
  - 冲煮表单正常显示。
- 首页、冲煮列表、日历中的新增冲煮入口行为一致。

### 使用说明

- 新用户首页显示 3 到 4 步使用步骤。
- 创建豆种后，步骤状态即时更新。
- 创建批次后，下一步骤解锁。
- 帮助按钮在桌面和移动端都能打开。
- 点击遮罩、关闭按钮和按 `Escape` 都能关闭说明。
- 中文和英文切换后，步骤卡和帮助弹窗文案完整切换。
- 深色模式下没有文字、背景或按钮对比度问题。
- 手机视口下帮助弹窗不超出屏幕，正文可以滚动。

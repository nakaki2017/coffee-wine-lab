# 变更记录

本文件记录面向用户可感知的功能变化；单次工作的技术细节见 `../work-items/`。

## 2026-09-23

### 多图豆种与咖啡配方库（开发中）

- 豆种档案增加最多 3 张图片、封面和顺序管理。
- 做法升级为配方库，区分冲煮做法和咖啡饮品。
- 配方增加最多 5 张图片、结构化原料和制作步骤。
- 增加配方详情、搜索、类型和器具筛选。
- 内置配方对登录用户可见，用户配方保持私有。
- 图片在浏览器压缩至 800KB 内，并使用私有 Supabase Storage。
- 云端 migration 和页面回归完成后再更新为正式发布状态。
- 配方库增加“冲煮做法 / 咖啡饮品”两个顶部入口。
- 冲煮做法保留完整冲煮参数；咖啡饮品改用饮品类型、原料和制作步骤。
- 内置配方增加中英文名称，用户配方仍使用单一自定义名称。
- 冷萃支持分别保存为浸泡冲煮做法或咖啡饮品。

详细记录：

- [多图豆种与咖啡配方库 Work Item](../work-items/2026-09-23-feat-多图豆种与配方库.md)
- [配方双入口与字段拆分 Work Item](../work-items/2026-09-23-feat-配方双入口与字段拆分.md)

## 2026-09-22

### 新手流程优化与使用说明

- 修复没有豆种档案时仍可进入无法保存的新建批次页面的问题。
- 库存、首页和批次表单现在会引导用户先建立豆种档案。
- 没有可用库存批次时，冲煮入口会提示先完成库存准备。
- 首页增加豆种、批次、冲煮、日历四步开始使用卡。
- 侧边栏和移动端菜单增加双语使用说明入口。
- 使用说明支持遮罩点击、关闭按钮和 `Escape` 关闭。
- 中英文文案、深色模式和移动端滚动状态同步覆盖。
- 该变更不新增数据库表，不修改 RLS、Storage 或现有业务数据。

详细记录：[新手流程与使用说明 Work Item](../work-items/2026-09-22-feat-新手流程与使用说明.md)。
